# Media performance: design constraints, not an active integration

Product data and media endpoints are not yet available. When the authenticated/authorized NestJS media API and malware scan are operational, product cards should request explicit width/height or aspect ratio, use responsive `next/image` `sizes`, lazily load below-the-fold images and preload only the actual LCP image. Only allow verified Cloudflare Images host/path patterns in Next image configuration; do not add permissive remote patterns or expose secrets. Use Cloudflare Stream only through a verified media adapter; defer embeds until consent/interaction where appropriate and respect reduced motion. Supabase S3 private documents require server-side authorization and short-lived scoped delivery; never expose permanent keys or make private objects public for caching. Never use product placeholders that imply real inventory.

No adapter, credentials, real upload, transcoding, malware scanning or authorized delivery is implemented by this document. For large future tables, use server-side scoped pagination and measure DOM/render cost before introducing virtualization; provide accessible table and chart alternatives. Cache decisions require authorization/tenant isolation and versioned invalidation defined in architecture/security governance.
