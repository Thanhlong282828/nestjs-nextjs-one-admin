- ERP đa công ty, đa chi nhánh và đa ngành; mọi truy vấn, API, cache, job, storage, media và báo cáo phải kiểm tra scope và permission phía server. Membership không tự cấp permission. Không tin tenant/company/branch ID hoặc quyền do client gửi.
- Admin là hệ thống quản trị; Product/khách là **website bán hàng**, không phải trang quảng cáo ERP. Chia sẻ thương hiệu nhưng giữ UX đúng mục đích. Thiết kế Premium Gold/champagne + macOS glass/vibrancy, dark/light, responsive, keyboard và accessibility theo `design-system/GLASS-DESIGN-STANDARD.md`. Không tự cập nhật visual baseline để che lỗi.
- Ưu tiên hoàn thiện HRM kết nối dữ liệu trước CRM/POS. Khi thêm chức năng, phân tích và duy trì quan hệ, authorization, audit, FK, transaction và các workflow liên quan; chỉ coi hoàn thành khi dữ liệu thật đi từ database → Prisma → repository/CQRS → NestJS API → Admin và được kiểm thử.
- Ảnh dự kiến Cloudflare Images, tài liệu private Supabase Storage S3; kiểm tra file và quét malware fail-closed trước lưu. Không tuyên bố đã tích hợp hay chống DDoS/ẩn dữ liệu DevTools nếu chưa thực sự triển khai và kiểm chứng. Tối ưu performance/monitoring/cache dựa trên phép đo và ranh giới tenant.
