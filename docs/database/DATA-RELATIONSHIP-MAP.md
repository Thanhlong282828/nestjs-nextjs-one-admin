## Prisma MySQL schema trong source — chưa đồng nhất với database đã xác minh

- `Company` (`companies`): `id` PK, `name`, `created_at`; quan hệ source một-nhiều Branch và CompanyMembership.
- `Branch` (`branches`): PK `id`, FK `company_id → companies.id`, unique `(company_id,id)`, index `(company_id,name)`.
- `IdentityUser` (`identity_users`): PK `id`, email unique, status; quan hệ source với membership và session. Không ghi password hash vào audit/tài liệu.
- `CompanyMembership` (`company_memberships`): PK `(company_id,user_id)`, FK tới company/user.
- `BranchGrant` (`branch_grants`): PK `(company_id,user_id,branch_id)`; FK ghép tới membership `(company_id,user_id)` và branch `(company_id,branch_id)` để không cấp nhầm company **theo schema**.
- `UserSession` (`identity_sessions`): FK `user_id`, token hash unique, expiry/revocation; `AuthenticationAudit` có `user_id` tùy chọn nhưng source không khai báo Prisma FK tới user. Không suy luận constraint vật lý nếu chưa inspect bằng quyền phù hợp.
- Source migration MySQL 001 company, 003 identity/org, 004 sessions, 005 auth audit; lịch sử áp dụng thực tế ở development chưa xác minh (`db:status` không kiểm tra migration).

## Đồ thị mục tiêu — không phải khẳng định implementation

- HRM: company → branch → department → employee → attendance/leave → payroll → approval → payment → accounting → report.
- CRM: company → customer/contact → lead/opportunity → quotation → order → invoice → payment → accounting.
- SCM/WMS: supplier → requisition/approval → PO → receipt → stock ledger → supplier invoice/payable → payment; warehouse → location → product → balance/movement → picking/packing/shipment.
- OMS: customer → cart → order → payment authorization/confirmation → fulfillment/shipment/delivery → invoice → accounting.
- BI: dữ liệu đã được phân quyền và scope → aggregate → KPI/dashboard/report → drill-down; REAL/DEMO không trộn tài chính.

Chuỗi trên chỉ mô tả phụ thuộc có thể có; nghiệp vụ, chứng từ, trạng thái, tenant scope và FK phải được kiểm chứng trước khi tạo quan hệ. Không sao chép nhân viên/khách hàng hay dựng kết quả thanh toán.
