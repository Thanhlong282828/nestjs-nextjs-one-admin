# ADR 0001: Native dialog with explicit keyboard loop and solid glass fallback

Status: implemented locally, verification pending. Use native `dialog.showModal()` for modality and accessible dialog semantics. At the first and last visible enabled controls, intercept Tab / Shift+Tab to keep keyboard focus within the dialog; Escape requests closure and native dialog returns focus to the opener. Do not hijack arrow keys in ordinary buttons or search inputs. Use opaque theme surface if backdrop filtering is unsupported or reduced transparency requested; forced-colors uses system colors. Trade-off: focusable selector must evolve when component supports shadow DOM or complex composite widgets. Browser tests and real assistive-technology review remain required; this does not establish WCAG conformance.
